# How often, and how much

- **Mode**: *balanced* (a couple of tips every half hour), *active* (as you work), *passive* (a summary in the evening) or *off*.
- **Your Vim level**: so the first tips aren't about things you know.
- **An AI**, if you want one, for `flowbuddy coach` and the weekly note: Claude Code, a local model or an API.
- **Profiles** set several at once: Gentle, Learning fast, Just watching, Already good at Vim.

Every setting is also in `flowbuddy config list`.
